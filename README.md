# UNEAKBEATZ Studio

Type a description, get a finished song with beat and vocals. Runs on your own computer; songs are saved in the `songs/` folder.

## Setup

1. Install [Node.js](https://nodejs.org) 20 or newer.
2. Get an API key from [ElevenLabs](https://elevenlabs.io) (Music API needs a paid plan).
3. Copy `.env.example` to `.env` and paste the key after `ELEVENLABS_API_KEY=`.
4. Run `npm start` and open http://localhost:3000.

## Using it

- **Generate song**: sends your description straight to the music model.
- **Write lyrics first**: free. Drafts the sections, lyrics and style tags so you can edit them, then generates audio from your edited version.
- Every song appears under **Your songs** with a player, MP3 download, and a button to reuse its prompt.

Audio is generated by ElevenLabs' `music_v2_5` model. Check their [music terms](https://elevenlabs.io/music-terms) for what your plan allows before releasing songs commercially.
